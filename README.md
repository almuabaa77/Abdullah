# وصلة | Waslah

منصة ثنائية اللغة لإدارة المعاملات بين العملاء والمعقّبين والإدارة. تشمل حسابات موثّقة بالجوال، ودليل خدمات تديره الإدارة، وعروض أسعار، وإسنادًا مباشرًا، وتتبعًا للطلبات ومراسلات ومرفقات.

## بدء التشغيل

يتطلب المشروع Node.js 24 أو أحدث. يحفظ SQLite البيانات في ملف خاص بمحرك التشغيل.

```sh
npm ci
npm run build
npm start
```

المنفذ الافتراضي `3000`. يبدأ دليل الخدمات فارغًا. بعد تفعيل التحقق بالجوال، يسجّل المدير الدخول برقم الإدارة ويسجّل العملاء والمعقّبون بأرقامهم. يوافق المدير على التسجيلات من لوحة التحكم ويحدد تخصص كل معقّب. تُنشَر الخدمات الحقيقية من قسم «إدارة الخدمات»، ويمكن للعميل تقديم طلب يدوي حتى لو لم يُنشَر الدليل بعد. الأسعار والمدد تأتي من عروض المعقّبين.

```sh
npm test
python3 -B -m unittest discover -v
```

تنشئ اختبارات Node حسابات مؤقتة في الذاكرة وتستخدم مزوّد تحقق داخل الاختبار.

## إعداد التشغيل الفعلي

يمكن استخدام Firebase Phone Authentication بدلًا من Twilio Verify، مع خيار رابط Firebase Hosting. راجع [دليل Firebase](FIREBASE.md).

شغّل الخادم خلف HTTPS واضبط الإعدادات في مخزن أسرار بيئة التشغيل. يدعم Node تحميل ملف محلي خاص عبر `node --env-file=.env server.mjs`.

| المتغير | الاستخدام |
| --- | --- |
| `NODE_ENV` | اضبطه على `production` لتفعيل ملفات ارتباط آمنة والتحقق من إعدادات الإقلاع. |
| `SESSION_SECRET` | مفتاح عشوائي ثابت لا يقل عن 32 حرفًا، مطلوب للإنتاج. تغيير المفتاح ينهي الجلسات. |
| `ADMIN_PHONE` | الجوال الدولي للمدير. ينشئ الخادم حساب الإدارة لهذا الرقم ويتحقق منه عبر مزود الرسائل المفعّل. |
| `AUTH_PROVIDER` و`FIREBASE_WEB_CONFIG` | اختيار Firebase وإعدادات تطبيق الويب العامة. يوضح دليل Firebase خطوات التفعيل. |
| `ADMIN_NAME` | اسم عرض الإدارة، اختياري. |
| `TWILIO_VERIFY_SERVICE_SID` | معرّف خدمة Twilio Verify مع تغطية البلد ورسائل SMS ورمز من ستة أرقام. |
| `TWILIO_ACCOUNT_SID` و`TWILIO_AUTH_TOKEN` | بيانات الاعتماد المعتادة لـTwilio Verify. |
| `TWILIO_VERIFY_AUTHORIZATION` | بديل لزوج Twilio السابق عند استخدام أسرار HTTP في Codex. ضع كامل قيمة ترويسة Basic كسر يقتصر على `verify.twilio.com`. |
| `DATABASE_PATH` | مسار SQLite على وحدة تخزين دائمة وخاصة. الافتراضي في الإنتاج `data/production.sqlite`. |
| `OPENAI_API_KEY` | يفعّل المحادثة عبر OpenAI. عند غياب المفتاح أو تعذّر الاتصال، يستخدم المساعد دليل المنصة وحالات الطلبات التي يحق للمستخدم الاطلاع عليها. |
| `OPENAI_MODEL` | اختياري، الافتراضي `gpt-4.1-mini`. |
| `PORT` | اختياري، الافتراضي `3000`. |

يستخدم الخادم `verify.twilio.com` للتحقق و`api.openai.com` عند إعداد المساعد. يرسل المساعد نص السؤال والمحادثة القصيرة والدليل المنشور إلى OpenAI عند التفعيل. يجيب محليًا عن رقم الطلب بعد التحقق من الصلاحية. تبقى المرفقات والبيانات من قاعدة الطلبات داخل المنصة.

المنصة تدير التقديم والعروض والإسناد والمتابعة. ينفّذ المعقّب المعاملة لدى الجهة المختصة. التسديد الإلكتروني والربط المباشر مع الجهات الخارجية يحتاجان مزودين وإعدادات خاصة بالجهة المشغّلة.

## مسار العمل والإدارة

- يبدأ الطلب من دليل منشور أو من طلب يدوي يقترح النموذج تصنيفه. يختار العميل المدينة وأولوية الترتيب بالتقييم أو بالمسافة التقريبية بين مراكز المدن. تظهر أسماء الطلبات وملخصاتها الاختيارية للمرشحين، وتظهر التفاصيل والمرفقات للعميل والإدارة والمعقّب المكلّف.
- يطابق النظام التخصص أولًا ويبدأ بالأول للإسناد المباشر أو بأول ثلاثة للعروض. تتسع المجموعة تدريجيًا، ويُستخدم التوزيع الاحتياطي عند غياب مختص متاح أو مرور ثلاثين دقيقة دون استجابة متخصصة مناسبة.
- في الإسناد المباشر يثبت أول قبول. في مسار العروض يختار العميل المبلغ والمدة المناسبين من عروض المعقّبين. تُغلق الفرصة لدى الآخرين عند تثبيت الإسناد. يراجع العميل سجل الأحداث والمراسلات ويقيّم المعقّب بعد إكمال الطلب.
- تعرض الطلبات الحيّة مؤشر «جاري البحث» فقط عند خلو القائمة. تظهر الطلبات تلقائيًا عند توفّرها. يمكن جدولة إيقاف الاستقبال من لوحة المعقّب أو ملفه. عند بلوغ ثلاثة طلبات نشطة يتوقف الإسناد الجديد حتى تُغلق الدفعة كاملة.
- يستطيع المدير تعديل حسابات المستخدمين وتعليقها وحظرها ورفع الحظر، مع سجل للتغييرات. ينهي الحظر كل جلسات الحساب فورًا. يمكن للمدير نشر الخدمات وإيقاف عرضها، وإعادة إسناد الطلبات أو إعادة طرحها.
- ترحيل قواعد البيانات القائمة يزيل الحسابات والطلبات التجريبية المعروفة ويحفظ السجلات غير المرتبطة بها. يظل الاسم المسجل للخدمة ظاهرًا في طلباتها السابقة عند تعديلها أو سحب نشرها.
